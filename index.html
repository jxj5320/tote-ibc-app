설정

촬영하면 바로 Claude API로 라벨 텍스트를 인식해요. API 키가 필요합니다. 입력한 키는 이 기기의 브라우저에만 저장되고, Claude API 요청 시에만 사용됩니다.
사진 안에 여러 코드/텍스트가 있어도, 위 접두어로 시작하는 코드만 찾아서 인식해요. 하이픈 위치는 라벨마다 달라도 괜찮아요. 새로운 접두어가 생기면 여기에 줄만 추가하면 됩니다.
이전에 다른 앱에서 쓰시던 키를 그대로 재사용하셔도 됩니다(같은 워크스페이스라면 앱마다 새로 발급받지 않아도 돼요).
